# ThriveRaft

ThriveRaft is a High-Performance, Distributed system that optimizes real-time scalable architecture, and streamlined console management via embedded agents.

With ThriveRaft, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ThriveRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ThriveRaft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
